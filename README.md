Nexa Cards is a modern and responsive frontend web application where users can:

✅ Browse different categories of NFC business cards  
✅ Explore product features and working process  
✅ View card pricing plans (Standard, Custom, Premium)  
✅ Customize cards and proceed to purchase  

Users do not need to log in to explore products.  
Login will be required only at the time of purchase.
